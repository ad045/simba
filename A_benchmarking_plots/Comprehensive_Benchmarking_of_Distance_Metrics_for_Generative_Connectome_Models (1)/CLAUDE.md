## LaTeX formatting conventions

- Use math mode for all numbers and variables in text, e.g. `$\eta$`, `$n = 100$`, `$r = -0.26$`.
- Use only hyphens (`-`) in prose. Never use en-dashes (`--`) or em-dashes (`---`) outside of math.
- Captions: dense, precise prose - one idea per sentence, no hedging. Do not break caption text with source-level newlines inside a sentence.
- The writing style reference for prose is `A_benchmarking_plots/degeneration_analysis_methods.tex` in the sister project.
- Cite so~\cite{first_citation}, and not so~\citep{second_citation}. 
- Always save any generated text to /Users/adrian/Documents/01_projects/14_4D_lab/scrap_book_latex_with_claude; feel free to create new files (of any sort) here. 
- Do not start newlines after a specific sentence width, but only after a sentence has ended. The latex interpreter handeles too long sentences, so this is not an issue.
