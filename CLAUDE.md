# CLAUDE.md - 14_4D_benchmarking

Code and data for *How Similar Are Two Brains? A Comprehensive Benchmark of Brain
Network Similarity Measures* (Dendorfer, Luppi, Poli, Mousley, Astle, Fakhar).
Manuscript repo: `~/Desktop/Benchmarking_` (its `CLAUDE.md` pins every published
number - check any number you touch against it).

## Layout (restructured for publication, 2026-09-25)

- `netdistancebench/` - the pip package. `measures.py` (16 measures as
  `f(A, B) -> float`, torch-free ports), `data.py` (bundle download, reference
  drop-in), `benchmark.py` (`evaluate`, `published_readouts`, every read-out).
- `tests/` - `pytest`: published read-outs vs Table S2, measures vs shipped
  distances, accuracy-only `evaluate`. Needs the data bundle, not the empirical data.
- `docs/` + `mkdocs.yml` - documentation site; `.github/workflows/docs.yml`
  deploys it to GitHub Pages on push to main.
- `paper/` - the research pipeline. **Run its scripts from `paper/`.**
  `paper/data` and `paper/output` are symlinks to `../../14_4D_lab_code/{data,output}`
  (gitignored, ~225 GB). `paper/experiments_config.py` is the single source of truth.

## Data bundle

`paper/make_publication_data.py` builds `paper/publication_data/netdistancebench-data/`
and the zip that is uploaded as GitHub release asset `data-v1`. It prints the
sha256; `DATA_SHA256` in `netdistancebench/data.py` must match the uploaded zip.
The empirical consensus is **not** shipped (HCP terms); users drop it at
`~/netdistancebench_data/reference/consensus.npy`. Only group-level summary
statistics of the empirical data are in the bundle.

## Hard-won facts

- Five measures are similarities (`jaccard`, `f1`, `communicability_corr`,
  `network_mutual_information`, `dc_network_mutual_information`); flip before
  any argmin. Package: `SIMILARITIES`; paper: `experiments_config.to_distance`.
- `published_readouts()` recomputes every Table S2 number from the shipped raw
  tables with the same code `evaluate()` uses. `evaluate(frobenius)` from scratch
  reproduces Frobenius's published MAE, CV, N*, iSNR and recovery exactly.
- Timing: the paper quotes the first `time_*` column of the 105 run's timing
  files (some have merged duplicates); the bundle ships that column.
- The non-backtracking spectral distance moves by up to ~1% between runs for a
  few networks (ARPACK); netrd behaves the same.
- Published run: `106_distance_metrics_mst_animal_0_density10`, generated by
  `paper/pipeline_gnms_and_benchmarking/generate_morphospace.py`, scored by
  `score_morphospace.py`.
