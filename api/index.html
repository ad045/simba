    API

    Evaluating a measure

    Score a network distance measure on the benchmark.

    Parameters:

    Name Type Description Default
    measure Callable[[ndarray, ndarray], float]

    f(A, B) -> float on two binary, symmetric (100, 100) float arrays; A is the generated network, B the reference.

    		 required
    name str | None

    label for the report (defaults to the function name).

    		 None
    similarity bool

    set True if higher values mean more alike.

    		 False
    reference ndarray | str | Path | None

    the empirical consensus connectome (array or .npy path). Defaults to data.reference_dir() / "consensus.npy". Only the accuracy criterion runs without it.

    		 None
    criteria Iterable[str]

    subset of ("agreement", "plausibility", "efficiency", "sensitivity", "accuracy"). Agreement, plausibility and efficiency share one pass over the 25,000 networks.

    		 CRITERIA
    n_jobs int

    worker processes (1 = in-process, -1 = all cores). With more than one, measure must be importable (defined in a module, not a lambda) and the per-comparison runtimes include pool overhead.

    		 1
    progress bool

    show progress bars.

    		 True

    Returns:

    Name Type Description
    A Report

    class:Report.

    Cost, in calls of measure: 25,000 for the landscape; 20,200 for the degeneration read-outs (MAE, CV); 20,000 for the two recovery experiments; and for the noise tolerance N one landscape per draw - 160 full ones for a fast measure, 80 windowed ones (4,410 calls each) for one slower than 10 ms. N dominates; leave out "sensitivity" to skip it.

    Result of :func:evaluate.

    Attributes:

    Name Type Description
    name str

    the name given to the measure.
    table DataFrame

    one row per read-out, the new measure next to the eight selected published measures, with each read-out's criterion, direction and the new measure's rank among the nine (1 = best).
    landscape DataFrame

    the new measure's value and runtime for every morphospace network.

    Every read-out of the published measures, recomputed from the shipped tables.

    Returns a DataFrame indexed by read-out key with one column per measure. Read-outs a measure was not run through (e.g. the degeneration experiments for the eight measures not selected) are NaN.

    Data

    Access to the benchmark data: the 25,000 generated networks, the recovery networks, every result table, and the empirical reference you drop in.

    In a clone of the repository the bundle is already there, as data/ next to this package. A pip install has no clone, so it downloads the same bundle once into ~/simba_networks_data (set SIMBA_HOME to move it)::

    ~/simba_networks_data/
    simba-networks-data/     downloaded on first use (about 30 MB)
    reference/
        consensus.npy          <- you put the empirical consensus here
        individuals.npy        <- optional, for the real-vs-artificial AUCs
        loo_consensuses.npy    <- optional, ditto

    The empirical connectomes are not distributed (HCP data use terms). See :func:load_reference and the documentation page "Reference connectome".

    load_networks(which='morphospace') cached

    Load a set of generated networks as boolean arrays.

    Parameters:

    Name Type Description Default
    which str

    "morphospace" (the 25,000 networks of the main sweep), "recovery_wide" or "recovery_window".

    		 'morphospace'

    Returns:

    Type Description
    tuple[ndarray, DataFrame] | dict

    For "morphospace", (networks, meta): networks of shape (25000, 100, 100) and meta a DataFrame of eta, gamma, replicate in the row order of load_table("landscapes"). For the recovery sets, a dict with grid (100 grid-point consensuses, gamma-outer / eta-inner), grid_members, targets (100 test networks) and grid_eta, grid_gamma, target_eta, target_gamma.

    load_table(name) cached

    Load one of the shipped result tables by name, e.g. "landscapes", "timing_ms", "degeneration", "recovery_wide", "noise_tolerance_draws", "real_vs_artificial" or "experiments/hub_topography/hub_topography_results".

    distance_matrix() cached

    Euclidean distance (mm) between the Schaefer-100 parcel centroids.

    empirical_summary() cached

    Group-level statistics of the empirical connectomes (no subject data).

    load_reference(reference=None)

    Return the empirical reference connectome as a float (100, 100) array.

    Parameters:

    Name Type Description Default
    reference ndarray | str | Path | None

    an array, a path to a .npy file, or None to read reference_dir() / "consensus.npy".

    		 None

    Warns if the array is not the consensus the published numbers were computed against, so that a mismatch cannot pass silently.

    reference_dir()

    Folder where :func:load_reference looks for consensus.npy.

    home()

    Root folder for the downloaded bundle and the dropped-in reference.

    data_dir()

    Path of the unpacked data bundle; downloads it on first call.

    Resolution order: SIMBA_DATA, the bundle in a repository clone, then the download into :func:home.

    Measures

    The 16 network distance measures benchmarked in the paper.

    Every measure is a plain function f(A, B) -> float on two binary, symmetric (N, N) adjacency matrices. A is the generated network and B the reference. The implementations are ports of the ones that produced the published numbers (paper/src/comparing_connectomes/) with torch removed; tests/test_measures.py checks them against the shipped values.

    Five of them are similarities (higher = more alike). They are listed in :data:SIMILARITIES, and :func:simba_networks.evaluate flips them before any ranking. A new measure declares its own direction with evaluate(..., similarity=True).

    frobenius(A, B)

    Frobenius norm of the difference, ||A - B||_F.

    hamming(A, B)

    Number of edges present in exactly one of the two networks.

    jaccard(A, B)

    Jaccard index of the two edge sets (similarity).

    f1(A, B)

    F1 score of A's edges against B's (similarity).

    network_mutual_information(A, B)

    Normalised mutual information between the two edge sets (similarity).

    dc_network_mutual_information(A, B)

    Degree-corrected normalised mutual information (similarity).

    spectral_distance_adjacency(A, B)

    L2 distance between the 50 largest-magnitude adjacency eigenvalues.

    spectral_distance_norm_laplacian(A, B)

    L2 distance between the 50 smallest normalised-Laplacian eigenvalues.

    netrd_non_backtracking_spectral(A, B)

    Non-backtracking spectral distance (Torres et al., 2019; netrd).

    Earth mover's distance between the leading eigenvalues of the two graphs' non-backtracking matrices, taken as points in the complex plane. ARPACK makes the eigenvalues vary in their last digits between runs; when an eigenvalue sits on the real axis that can move a value by up to about 1% (netrd behaves the same).

    net_simile(A, B)

    NetSimile (Berlingerio et al., 2012; netrd): Canberra distance between the graphs' signatures of seven local node features.

    resistance(A, B)

    Resistance-perturbation distance (Monnig and Meyer, 2018; netrd): L2 norm of the difference of the effective-resistance matrices.

    portrait(A, B)

    Portrait divergence (Bagrow and Bollt, 2019).

    delta_con(A, B)

    DeltaCon: Matusita distance between fast-belief-propagation affinities.

    communicability_corr(A, B)

    Pearson correlation of the two communicability matrices (similarity).

    communicability_jsd(A, B)

    Jensen-Shannon divergence between the normalised communicability matrices.

    energy(A, B, distance_matrix=None)

    KS-based energy: the largest of four KS statistics (degree, clustering, betweenness, edge length) between A and B.

    The edge-length term needs the node-to-node distance matrix. When it is not given, the Schaefer-100 matrix of the benchmark is used, so this default only makes sense for 100-node networks in that parcellation.
